# Fresh Cool — فريش كول لخدمات المكيفات بالرياض

الصفحة الرئيسية الرسمية الاحترافية لموقع شركة خدمات المكيفات والتكييف في مدينة الرياض، مبنية بتقنيات الويب القياسية (HTML5، Tailwind CSS v3 محليًا، Vanilla JavaScript)، مع دعم كامل لاتجاه اللغة العربية (RTL)، وتهيئة تقنية شاملة لمحركات البحث (Technical SEO)، وتجربة مستخدم مخصصة لتحقيق أعلى معدلات التحويل والسرعة.

---

## 1. الهيكل التقني والملفات

```text
clean-air/
├── index.html               # الصفحة الرئيسية الكاملة لخدمات المكيفات بالرياض
├── 404.html                 # صفحة الخطأ 404 المتوافقة مع هوية الموقع
├── package.json             # تعريف المشروع والاعتماديات وأوامر البناء
├── tailwind.config.js       # إعدادات Tailwind CSS v3 ولوحة الألوان والخطوط
├── postcss.config.js        # إعدادات PostCSS لمعالجة CSS وAutoprefixer
├── robots.txt               # تعليمات عناكب البحث وفهرسة الموارد
├── sitemap.xml              # خريطة الموقع لمحركات البحث
├── src/
│   └── input.css            # ملف المصدر الأساسي، الخطوط المحلية، ومتغيرات الألوان
├── css/
│   └── style.css            # ملف CSS النهائي المترجم محليًا للإنتاج
├── js/
│   ├── config.js            # إعدادات الموقع، أرقام التواصل، الخدمات، وأحياء الرياض
│   └── main.js              # المنطق التفاعلي، القائمة، الأكورديون، وتتبع النقرات
└── assets/
    ├── fonts/               # خط Cairo بجميع أوزانه محليًا (400, 500, 600, 700)
    ├── images/              # الصور الأصلية المحسنة بدقة وأبعاد واضحة
    └── icons/               # الأيقونات والشعارات الرسومية
```

## 3. أوامر التطوير والبناء

### لتثبيت الاعتماديات (عند نسخ المشروع إلى بيئة جديدة):
```bash
npm install
```

### لبناء ملفات CSS محليًا لنسخة الإنتاج (Minified):
```bash
npm run build
```

### لمتابعة التعديلات أثناء التطوير (Watch Mode):
```bash
npm run dev
```

### لتشغيل خادم معاينة محلي:
يمكن فتح `index.html` مباشرة في المتصفح أو تشغيل خادم بسيط مثل:
```bash
npx serve .
# أو
python -m http.server 8000
```

## 4. تخصيص بيانات التواصل والتحويلات (`js/config.js`)

تم بناء الموقع بفلسفة صارمة تمنع نشر بيانات وهمية (بدون أرقام هواتف وهمية أو تقييمات غير حقيقية):

1. **إضافة رقم الهاتف المعتمد:**
   افتح `js/config.js` وضع الرقم في:
   ```javascript
   contact: {
     phone: '+9665XXXXXXXX', // سيتم تفعيل زر الاتصال تلقائيًا في كل الموقع
   }
   ```
2. **إضافة رقم واتساب:**
   ```javascript
   contact: {
     whatsapp: '9665XXXXXXXX', // سيتم إظهار زر واتساب ورابط المحادثة المباشرة فورًا
   }
   ```
3. **ربط تتبع الإحصاءات:**
   ضع معرف GTM أو GA4 في كائن `analytics` داخل `js/config.js` وسيتكفل ملف `js/main.js` بتسجيل النقرات والتحويلات تلقائيًا.

## 5. ميزات SEO والأداء وإمكانية الوصول

- **وسوم الميتا الدقيقة:** العنوان الرئيسي H1 مخصص لخدمات المكيفات بالرياض، وتفرد كامل للعناوين الفرعية.
- **البيانات المنظمة (JSON-LD):** كائن `HomeAndConstructionBusiness` دقيق يتضمن كتالوج خدمات التكييف المعتمدة بدون تلفيق لتقييمات أو بيانات غير صحيحة.
- **إمكانية الوصول (Accessibility):**
  - رابط تخطي إلى المحتوى الرئيسي (`.skip-link`).
  - دعم كامل للتنقل بلوحة المفاتيح والتركيز البصري الواضح (`:focus-visible`).
  - دعم شاشات القراءة وخصائص ARIA في القائمة (`aria-expanded`) والأكورديون (`aria-controls`).
  - احترام تفضيلات تقليل الحركة (`prefers-reduced-motion`).
- **الخطوط:** تم تنزيل خط **Cairo** بأوزان 400 و500 و600 و700 محليًا في صيغة `woff2` الخفيفة لتفادي الاعتماد على شبكات خارجية وتسريع LCP.
